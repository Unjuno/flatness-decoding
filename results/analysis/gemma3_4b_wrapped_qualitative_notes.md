# Gemma wrapped qualitative notes

Wrapped20 is a completed modern instruct-model sanity check, not a benchmark.

The wrapper appears to suppress the obvious task-drift artifacts that showed up in the raw setting, but the surviving behavior is not clearly better. The dominant residual pattern is generic atmospheric prose, especially rain / metal / rust / regret openings. That looks more like a strong continuation prior than a quality win.

Method-level differences still exist inside the wrapped condition. Center-flat and high-probability selectors look more likelihood-friendly, while minflat and maxflat move the rank / dispersion profile in the expected directions. The text itself does not support any robust format-control claim, and story openings remain fairly homogeneous across methods.
