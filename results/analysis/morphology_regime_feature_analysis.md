## 17形状を一つずつ読む

### 1. `low_spread`

狭い logits 幅。ただし top1 が高いモデルでは、平坦というより単一候補への集中として現れる。
3モデル平均は std=2.543, top1=0.665, tail50=0.111, gap=3.363。モデル間レンジは std=0.527, top1=0.562, tail50=0.167, gap=4.696。
モデル差が大きく、形状名よりもモデル固有の logit スケール／tokenizer の影響が強い。

### 2. `mid_spread`

中程度の幅。top1・tail・gap が中間になり、最も通常的な遷移候補になりやすい。
3モデル平均は std=2.971, top1=0.359, tail50=0.215, gap=1.232。モデル間レンジは std=0.250, top1=0.371, tail50=0.323, gap=1.218。
top1 より tail のモデル差が目立つため、同じ形状でも探索性の意味は一致しない。

### 3. `high_spread`

広い logits 幅。ただし tail が増えるとは限らず、尖った多峰性も含むため spread 単独では不十分。
3モデル平均は std=3.480, top1=0.440, tail50=0.185, gap=1.956。モデル間レンジは std=0.579, top1=0.451, tail50=0.307, gap=2.758。
top1 より tail のモデル差が目立つため、同じ形状でも探索性の意味は一致しない。

### 4. `low_concentration`

top1 が低く tail が厚い拡散型。候補の選択余地は大きいが、接地性は弱くなりやすい。
3モデル平均は std=3.158, top1=0.188, tail50=0.289, gap=0.395。モデル間レンジは std=0.106, top1=0.252, tail50=0.419, gap=0.095。
top1 より tail のモデル差が目立つため、同じ形状でも探索性の意味は一致しない。

### 5. `mid_concentration`

集中と拡散の中間。複数候補を残しつつ、完全な diffuse 状態を避ける。
3モデル平均は std=3.104, top1=0.358, tail50=0.183, gap=1.100。モデル間レンジは std=0.106, top1=0.428, tail50=0.279, gap=1.011。
top1 より tail のモデル差が目立つため、同じ形状でも探索性の意味は一致しない。

### 6. `high_concentration`

top1 と gap が大きく tail が薄い単峰型。安定するが、反復・保守性のリスクがある。
3モデル平均は std=3.015, top1=0.767, tail50=0.061, gap=4.372。モデル間レンジは std=0.857, top1=0.511, tail50=0.108, gap=4.335。
モデル差が大きく、形状名よりもモデル固有の logit スケール／tokenizer の影響が強い。

### 7. `thin_tail`

上位候補に確率が集まり tail が薄い。large-gap/high-concentration とほぼ同じ状態を別名で検出している。
3モデル平均は std=3.027, top1=0.755, tail50=0.040, gap=4.145。モデル間レンジは std=0.921, top1=0.506, tail50=0.060, gap=4.403。
モデル差が大きく、形状名よりもモデル固有の logit スケール／tokenizer の影響が強い。

### 8. `mid_tail`

モデル差が大きく、形状名よりもモデル固有の logit スケール／tokenizer の影響が強い。

## 重要な発見

1. `low_spread` はモデル共通の意味ではない。GPT-2 では top1=.644、Gemma raw では .957、Qwen raw では .395で、同じ spread 条件が尖った分布から競合分布まで変わる。
2. `high_spread` も単純な diffuse ではない。GPT-2 は top1=.525、Gemma raw は .623、Qwen raw は .172で、spread と concentration は別軸として保存すべきである。
3. `high_concentration`、`thin_tail`、`large_gap` は多くの条件で重複した状態を別の検出器が拾っている。18種類を独立な18形状と解釈するより、基礎軸（spread/concentration/tail/gap/token type）の組合せと見るべきである。
4. `prompt_overlap_heavy` と `recent_overlap_heavy` は、GPT-2/Qwen raw ではほぼ同じ統計値であり、実質的に同じ検出状態に落ちている可能性がある。形状として分離するには token 内容と時系列の追加分析が必要である。
5. Gemma raw は top1 と gap が大きく tail が薄い形状が多く、Qwen raw は tail が厚く top1 が低い形状が多い。したがって、同じ selector quantile をモデル間で共有するのは危険である。

## 解釈上の注意

- これは各レジームを意図的に選んだ probe であり、自然発生頻度の推定ではない。
- `mean_successor_logit_std` は raw logit の標準偏差で、Shannon entropy ではない。
- regime は閾値ベースの検出器で重複し得る。特に concentration/tail/gap のレジームは独立条件ではない。
- 「18種類」は現行 CSV では17種類。欠落した1種類があるなら、元の run 設定またはラベル生成部を確認する必要がある。
